# AWS Serverless Web Application

## 🏗️ Architecture
- **Frontend:** Static HTML/CSS/JS hosted on AWS S3 (Region: `eu-central-1`)
- **CDN:** AWS CloudFront
- **Backend:** Node.js (AWS Lambda) via API Gateway
- **Databases:** AWS DynamoDB & AWS RDS (MySQL)
